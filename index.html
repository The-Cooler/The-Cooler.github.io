P01

zst自学通

基于 LangGraph 的个人知识库：上传 PDF / Word / Markdown 或抓取网页，LightRAG 做向量与图谱双路召回，Neo4j 输出可交互知识图谱。

  • LangGraph
  • LightRAG
  • pgvector
  • Neo4j
  • FastAPI
  • Vue
↗ P02

visio-diagramVisio 图表 Skill

用 Microsoft Visio 生成 .vsdx 图的 Claude Skill：ER 图、流程图、时序图按规则拆分在 references/ 按需加载，脚本经合同校验后由本机 Visio COM 出图，支持分析并注册新模板。

  • Claude Skill
  • Visio COM
  • ER 图
  • 流程图
  • 时序图
  • 模板注册
↗ P03

Agent_demo最小 Agent 实现

不依赖 LangGraph / LangChain 等 Agent 框架，从零实现最小可用 Agent：ReAct 循环、工具注册、多 session 与 context 管理、trace 全部手写，FastAPI 提供对话界面与接口文档。

  • ReAct
  • 工具调用
  • 多 session
  • FastAPI
  • uv
↗ P04

ds-web-plug大飞鱼插件

运行于 DeepSeek 网页的油猴脚本：多模板自定义提示词在对话请求里注入一次即生效；附带大飞鱼桌宠挂件，支持拖拽、甩抛、点击回应与随机动作。

  • Tampermonkey
  • JavaScript
  • 提示词注入
  • 桌宠动画
↗ P05

langchain_lunwen论文 AI 编写

LangChain + RAG 的论文生成流水线：从素材提取到向量库构建，Agent 按模板逐章写入，终端流式输出进度，最终产出 Word 文档。

  • LangChain
  • RAG
  • 向量库
  • uv
  • docx
