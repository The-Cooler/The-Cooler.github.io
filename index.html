P01

zst自学通

基于 LangGraph 的个人知识库：上传 PDF / Word / Markdown 或抓取网页，LightRAG 做向量与图谱双路召回，Neo4j 输出可交互知识图谱。

  • LangGraph
  • LightRAG
  • pgvector
  • Neo4j
  • FastAPI
  • Vue
↗ P02

-elevator-platform电梯维保平台

老旧小区电梯故障报修与维保跟踪：面向业主、物业、维修员、管理员四类角色，串起报修、工单调度、预防性维保与数据分析预警。后端 Spring Boot，管理端与用户端各自独立，地图定位用高德 JS API。

  • Spring Boot
  • Vue 3
  • MyBatis
  • MySQL
  • Redis
  • Quartz
  • ECharts
  • 高德地图
↗ P03

yolo_fall_down摔倒检测

YOLOv8 + OpenCV 实时检测摔倒行为，按置信度与持续时间输出三档告警；Python 推理与 Java 业务微服务解耦，支持多路视频并发。

  • YOLOv8
  • OpenCV
  • Python
  • Java
  • Redis
↗ P04

ssh-agent远程运维 Agent

基于 pi SDK 的远程 SSH Agent：模型只能通过项目提供的 SSH 工具访问指定目标机器与目录，按会话、项目、全局三层白名单收敛可执行操作。

  • TypeScript
  • Node.js
  • pi SDK
  • SSH
↗ P05

langchain_lunwen论文 AI 编写

LangChain + RAG 的论文生成流水线：从素材提取到向量库构建，Agent 按模板逐章写入，终端流式输出进度，最终产出 Word 文档。

  • LangChain
  • RAG
  • 向量库
  • uv
  • docx
↗ P06

question_tool题目练习工具

基于 PyQt5 的桌面刷题工具：CSV 导入题库，随机抽题、提交判分、叉掉不再出现的题，并自动保存历史记录；另附 Windows 安装包打包流程。

  • PyQt5
  • Python
  • CSV
  • Inno Setup
